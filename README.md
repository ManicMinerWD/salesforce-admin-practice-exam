# Salesforce Platform Administrator — Practice Exam

Interactive practice exam for the **Salesforce Certified: Platform Administrator** (CRT-101 / ADM-201),
grounded in the official exam outline (Summer '25): 60 questions, 105 min, pass mark 68%.

- 35 practice questions weighted to the official domain percentages:
  - Configuration and Setup 15% · Object Manager & Lightning App Builder 15% · Data & Analytics 17% · Automation 15% · Sales & Marketing 10% · Service & Support 10% · Productivity & Collaboration 10% · Agentforce 8%
- Study mode (per-question "Reveal answer") and Exam mode (answers hidden, 105-min countdown, auto-submit)
- Score + per-domain breakdown + weakest-area study bullets
